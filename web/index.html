1快速开始

安装 Node.js 20+ 与 Git 后，克隆仓库并启动。

安装

# 安装 Node.js(https://nodejs.org) 与 Git(https://git-scm.com) 后:
git clone https://github.com/arsya371/prenivdlapp-cli.git
cd prenivdlapp-cli
npm install
node index.js
sudo apt update && sudo apt install nodejs npm git -y

cd prenivdlapp-cli
npm install
node index.js

npm install
node index.js
pkg update && pkg upgrade
pkg install nodejs git

启动方式：无参数运行 node index.js 进入交互模式；Windows 可直接双击 prnvapp.bat，Linux/macOS 可用 ./prnvapp.sh。全局安装后可直接使用 prnvapp 命令。

2交互模式

启动后直接粘贴任意支持的 URL 即可自动识别平台并下载；输入 / 开头的命令可管理会话。

命令作用
/help显示可用命令
/tutor显示快速教程
/platform列出所有支持的平台
/clear清屏
/path显示当前下载目录
/setpath <目录>设置自定义下载目录
/quit 或 /exit退出应用
 
prenivdlapp » /setpath my_downloads
✔ Download path set to: my_downloads
prenivdlapp » /path
Current download path: my_downloads

3命令行模式

不用交互，直接指定平台与 URL 一步完成下载，支持别名与自定义路径。

# 语法: node index.js <平台> <url> [-p 目录]
node index.js tiktok https://www.tiktok.com/@user/video/123
node index.js ig https://www.instagram.com/p/ABC123/        # 别名 ig = instagram
node index.js -p my_downloads yt https://youtu.be/ABC123   # 指定下载目录
提示：若直接运行 node index.js，则进入交互模式（无参数时不会进入命令行分发）。命令行动作自动识别平台，正确 URL 即可。

6更新与部署

从仓库拉取最新代码，安装依赖（基于已提交的 lockfile，保证可复现），发布走自动工作流。

# 更新
cd prenivdlapp-cli
git pull origin main
npm ci

# 发布新版本(推送 v 前缀标签触发 GitHub Actions 自动测试并 npm publish)
git tag v1.4.0
git push origin v1.4.0
CI 检查：推送到 GitHub 后，CI 会在 Node 20/22 × Windows/Linux/macOS 上运行 npm test，并校验语法与 npm pack 发布内容。

7本地开发

测试使用 Node 内置 test runner，零额外依赖，离线可跑。

npm start                  # 运行 CLI
npm test                   # 运行单元测试(node:test)
npm run test:coverage      # 运行测试并输出覆盖率
npm run check             # 语法检查 + 全部测试
npm run check:syntax       # 仅语法检查全部 JS 文件
